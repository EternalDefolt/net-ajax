# net.ajax

Работы по предмету net.ajax (ASP.NET Core). Каждое домашнее задание в своей ветке.

## Ветки

- `znakomstvo` - создание и запуск проекта ASP.NET Core, добавление элементов в HTML
- `anketa` - веб-приложение с заявкой, после отправки выводится успех и анкета
- `scheduler-api` - API планировщика задач с расписанием версий (v2 отдаёт два дополнительных поля)
- `middleware-lifecycle` - форма, своё middleware, жизненный цикл приложения
