# Заявка и анкета

Своё веб-приложение на ASP.NET Core (Razor Pages). Пользователь заполняет заявку,
после отправки показывается сообщение об успехе и анкета с введёнными данными.

## Как работает

- Форма заявки: ФИО, возраст, email, телефон, город, о себе
- Поля проверяются на сервере (обязательные, формат email, диапазон возраста)
- После успешной отправки на той же странице выводится "Заявка успешно отправлена" и анкета

Код формы и обработки: `Anketa/Pages/Index.cshtml` и `Anketa/Pages/Index.cshtml.cs`
